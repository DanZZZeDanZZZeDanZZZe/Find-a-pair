# Find-a-pair

## Русская версия

### О проекте

Этот проект был создан в 2018 году как курсовая работа и сохранён в оригинальном виде как свидетельство моего профессионального роста и развития навыков программирования. Он отражает мой первый опыт создания полноценного веб-приложения с использованием JavaScript и служит отправной точкой моего пути в веб-разработке.

### Описание

Find-a-pair - это увлекательная браузерная игра, в которой нужно находить пары одинаковых цветных блоков. Игра разработана с использованием HTML, CSS и JavaScript.

### Запуск проекта

1. Склонируйте репозиторий на локальный компьютер
2. Откройте файл `Find-a-pair.html` в любом современном браузере
3. Готово! Можно начинать игру

### Требования

- Любой современный веб-браузер с поддержкой HTML5 и CSS3
- Не требуется установка дополнительных зависимостей или сборка проекта

### Функционал

- Несколько уровней сложности с разными конфигурациями
- Система жизней
- Таймер для каждого уровня
- Таблица рекордов
- Анимации и визуальные эффекты

### Уровни

1. **Начало пути** - Стартовый уровень с базовой механикой (5x8 блоков)
2. **Дискотека** - Увеличенное поле и дополнительные механики (6x9 блоков)
3. **Босиком по болоту** - Уровень с зелёной цветовой гаммой (6x8 блоков)
4. **Маленькая деревушка** - Серая цветовая гамма с усложнённой механикой (6x8 блоков)
5. **Кисельные берега** - Розовая цветовая гамма с вращением блоков (8x8 блоков)
6. **Без права на ошибку** - Сложный уровень с одной жизнью (5x5 блоков)
7. **Водоворот** - Финальный уровень с синей цветовой гаммой

### Технологии

- HTML5
- CSS3 (включая анимации)
- JavaScript (ООП подход)

### Структура проекта

- `src/styles/` - CSS стили
- `src/scripts/` - JavaScript файлы
- `src/fonts/` - Шрифты
- `src/image/` - Изображения

## English version

### About

This project was created in 2018 as coursework and has been preserved in its original form as evidence of my professional growth and programming skills development. It reflects my first experience in creating a full-fledged web application using JavaScript and serves as a starting point in my web development journey.

### Description

Find-a-pair is an engaging browser game where you need to find pairs of identical colored blocks. The game is developed using HTML, CSS, and JavaScript.

### Project Launch

1. Clone the repository to your local computer
2. Open the `Find-a-pair.html` file in any modern browser
3. Done! You can start playing

### Requirements

- Any modern web browser with HTML5 and CSS3 support
- No additional dependencies or project build required

### Features

- Multiple difficulty levels with different configurations
- Lives system
- Timer for each level
- High scores table
- Animations and visual effects

### Levels

1. **First Steps** - Starter level with basic mechanics (5x8 blocks)
2. **Disco** - Larger field and additional mechanics (6x9 blocks)
3. **Barefoot in the Swamp** - Level with green color scheme (6x8 blocks)
4. **Small Village** - Grey color scheme with complex mechanics (6x8 blocks)
5. **Kissel Shores** - Pink color scheme with rotating blocks (8x8 blocks)
6. **No Room for Error** - Challenging level with one life (5x5 blocks)
7. **Whirlpool** - Final level with blue color scheme

### Technologies

- HTML5
- CSS3 (including animations)
- JavaScript (OOP approach)

### Project Structure

- `src/styles/` - CSS styles
- `src/scripts/` - JavaScript files
- `src/fonts/` - Fonts
- `src/image/` - Images
