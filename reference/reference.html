Справка

Суть игры заключается в поиске пары одинакового цвета. На каждом уровне, есть только одна пара одинакового цвета

На каждом уровне есть жизни. Когда счётчик доходит до нуля игроку засчитывается поражение

На уровнях так же есть счётчик времени. Если он опускается до нуля, игроку засчитывается поражение

Иногда клетки закрашиваются серым, на некоторый период времени. Отгдавыать цвета нужно по памяти

На некоторых уровнях для усложнения игры поле делает поворот
